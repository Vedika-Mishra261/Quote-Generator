# Random Quote Generator

A simple and user-friendly Random Quote Generator built using HTML, CSS, and JavaScript. This project displays a random inspirational quote along with its author's name whenever the user clicks the button.

## 📌 Project Overview

The Random Quote Generator is a beginner-friendly web development project created as part of my Veda Technology internship.

The main purpose of this project is to practice JavaScript concepts such as arrays, objects, random numbers, event handling, and DOM manipulation.

## ✨ Features

- Displays random inspirational quotes.
- Shows the author's name with each quote.
- Contains multiple quotes stored in JavaScript.
- Generates a new quote with a button click.
- Avoids showing the same quote twice consecutively.
- Clean and user-friendly interface.
- Responsive design for different screen sizes.
- Optional share or copy quote functionality.

## 🛠️ Technologies Used

- HTML5 – For creating the structure of the website.
- CSS3 – For styling and designing the user interface.
- JavaScript – For generating random quotes and handling user interactions.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in your web browser.
4. Click the **New Quote** button to generate a random quote.

## 💡 How It Works

1. Quotes are stored in an array of JavaScript objects.
2. Each object contains a quote and its author's name.
3. JavaScript uses `Math.random()` to select a random quote.
4. The selected quote and author are displayed on the webpage.
5. The user can click the button again to generate another quote.
